# 浙教版数学七年级 核心知识梳理

## 适用说明

- 版本：浙江教育出版社《数学》（浙教版），浙江省初中统一使用；覆盖七年级上、下两册。
- 上册：有理数、有理数的运算、实数、代数式、一元一次方程、图形的初步知识。下册：平行线、二元一次方程组、整式的乘除、因式分解、分式、数据与统计图表。
- 用途：复习检索与知识自查的本地依据；章节编号与课时安排以学生所用课本为准。

## 核心概念与知识框架

### 一、有理数
- 有理数：整数和分数统称有理数；分为正有理数、0、负有理数。
- 数轴：规定了原点、正方向、单位长度的直线，右边的数总比左边的大。
- 相反数：只有符号不同的两个数，a 的相反数是 -a，0 的相反数是 0。
- 绝对值：数轴上表示数 a 的点到原点的距离，记作 |a|，|a|≥0；a≥0 时 |a|=a，a≤0 时 |a|=-a。
- 倒数：a 与 1/a（a≠0）互为倒数。大小比较：正数>0>负数；两负数比较，绝对值大的反而小。

### 二、有理数的运算
- 加法：同号相加取相同符号、绝对值相加；异号相加取绝对值较大者的符号，用较大绝对值减较小绝对值；互为相反数相加得 0。
- 减法：a-b=a+(-b)。
- 乘法：同号得正、异号得负，绝对值相乘；任何数同 0 相乘得 0。
- 除法：除以一个不为 0 的数，等于乘它的倒数。
- 乘方：aⁿ 表示 n 个 a 相乘；负数偶次幂为正、奇次幂为负。
- 混合运算：先乘方，再乘除，最后加减；有括号先算括号；同级从左到右。
- 科学记数法：a×10ⁿ（1≤|a|<10，n 为整数）。

### 三、实数
- 平方根：若 x²=a（a≥0），x 叫 a 的平方根；正的平方根叫算术平方根，记作 √a；0 的平方根是 0，负数没有平方根。
- 立方根：若 x³=a，x 叫 a 的立方根，记作 ∛a；正数立方根为正，负数立方根为负。
- 无理数：无限不循环小数（π、√2 等）；实数=有理数+无理数。

### 四、代数式
- 单项式（系数、次数）、多项式（项、次数）、整式。
- 同类项：所含字母相同且相同字母的指数也相同；合并同类项时系数相加，字母和指数不变。
- 去括号：括号前是"+"各项不变号，是"-"各项都变号。
- 求代数式的值：先化简再代入，能整体代入就整体代入。

### 五、一元一次方程
- 只含一个未知数、未知数次数为 1、等号两边都是整式的方程。
- 等式性质：两边同加（减）同一个数或整式仍是等式；两边同乘（除以）同一个不为 0 的数仍是等式。
- 步骤：去分母（乘各分母最小公倍数，不漏乘不含分母的项，分子加括号）→去括号→移项（变号）→合并同类项→系数化为 1。
- 应用：行程、工程、销售折扣、分配、数字问题，关键是找等量关系。

### 六、图形的初步知识
- 两点确定一条直线；两点之间线段最短。
- 线段中点：AP=PB=AB/2；1°=60′，1′=60″；角平分线把角分成两个相等的角。
- 余角、补角：和为 90°、和为 180°；同角（等角）的余角相等、补角相等。
- 对顶角相等；过一点有且只有一条直线与已知直线垂直，垂线段最短。

### 七、平行线（下册）
- 三线八角：同位角、内错角、同旁内角。
- 判定：同位角相等、内错角相等或同旁内角互补，两直线平行；平行于同一条直线的两条直线互相平行。
- 性质：两直线平行，同位角相等、内错角相等、同旁内角互补。
- 平移：形状大小不变，对应点所连线段平行（或在同一直线上）且相等。

### 八、二元一次方程组（下册）
- 解法：代入消元法、加减消元法，核心是消元，转化为一元一次方程。
- 应用：设两个未知数、列两个方程，常见和差倍分、配套、销售问题。

### 九、整式的乘除（下册）
- aᵐ·aⁿ=aᵐ⁺ⁿ；(aᵐ)ⁿ=aᵐⁿ；(ab)ⁿ=aⁿbⁿ；aᵐ÷aⁿ=aᵐ⁻ⁿ（a≠0）；a⁰=1（a≠0）。
- 多项式乘法：m(a+b)=ma+mb；(a+b)(c+d)=ac+ad+bc+bd。
- 平方差公式 (a+b)(a-b)=a²-b²；完全平方公式 (a±b)²=a²±2ab+b²。

### 十、因式分解（下册）
- 把多项式化成几个整式的积，与整式乘法互逆。
- 一般顺序：先提公因式，再用公式法（平方差、完全平方），分解要彻底。

### 十一、分式（下册）
- 分式 A/B 有意义：B≠0；分式值为 0：A=0 且 B≠0。
- 基本性质：分子分母同乘（除以）同一个不为 0 的整式，分式值不变；约分、通分、分式的加减乘除。
- 分式方程：去分母化为整式方程，解出后必须检验，防止增根。

### 十二、数据与统计图表（下册）
- 条形图、折线图、扇形图的特点；频数分布直方图（组距、频数、频率=频数÷总数）。
- 全面调查与抽样调查；用样本估计总体。

## 重点公式/规律/结论

- |a|≥0，a²≥0，√a≥0（a≥0）。
- 一元一次方程 ax=b：a≠0 时 x=b/a；a=0 且 b=0 时无数个解；a=0 且 b≠0 时无解。
- 完全平方公式的中间项是两数乘积的 2 倍，符号可正可负。
- 平方差公式的结构：两个数的和乘这两个数的差，结果是平方的差。

## 典型例题与解题思路

**例 1** 计算：-2²+(-2)³÷4-(-1/2)×|-6|。

解：-2²=-4；(-2)³÷4=-8÷4=-2；(-1/2)×6=-3，减去(-3)即加 3。原式=-4-2+3=-3。

思路：先乘方，再乘除，最后加减。-2² 表示 2 的平方的相反数，与 (-2)² 不同；减去一个负数要变加。

**例 2** 解方程：(x-1)/2-(2x+1)/3=1。

解：两边乘 6，得 3(x-1)-2(2x+1)=6；去括号 3x-3-4x-2=6；合并得 -x=11，所以 x=-11。

思路：去分母时右边常数项也要乘 6；分子是多项式，去分母后要整体加括号。

## 易错点与常见误区

1. 把 -2² 算成 4，(-2)³ 的符号算错。
2. 移项不变号；去括号只变第一项。
3. 去分母漏乘不含分母的项。
4. 因式分解不彻底，如 2a³-8a 只写到 2a(a²-4)。
5. 解分式方程忘记检验，把增根当成解。
6. 混淆平方根与算术平方根；误以为负数可以开平方。
7. 混淆平行线的判定（由角推平行）与性质（由平行推角）。

## 与考试的联系

- 浙江中考高频考点：有理数与实数运算、整式运算与因式分解、一元一次（二元一次）方程、分式化简求值、平行线与角、统计图表。
- 选择填空考概念与简单计算；解答题考方程应用与"先化简再求值"；运算是七年级的核心能力，符号准确率直接影响后续学习。
